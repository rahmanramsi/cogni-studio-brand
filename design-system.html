03 — Visual Style

Estetika & Arah Visual

Clean, modern, approachable — bukan corporate kaku. Setiap elemen harus earn its place.

3 Prinsip Visual

Whitespace = Design
Ruang kosong bukan kekosongan — itu nafas konten. Minimum margin antar section: 48px. Setiap elemen butuh ruang personal agar pesan dapat dipahami dengan cepat.
Hierarki Jelas
Mata pembaca harus tahu mana paling penting dalam 3 detik pertama. Gunakan ukuran, weight, dan warna — bukan dekorasi — untuk hierarki informasi.
Satu Aksen per Layout
Orange hanya muncul sekali per slide/kartu sebagai "hero". Kalau semua penting, tidak ada yang penting. Fokus aksen = fokus audiens.

Do's & Don'ts

Lakukan
✓
Grid bersih — 12-column, gutter konsisten (24px mobile, 32px desktop)
✓
Satu pesan utama per visual — takeaway dalam 5 detik
✓
Bold headline + body tenang — kontras menciptakan ritme baca
✓
Data dengan konteks — setiap angka diberi penjelasan
✓
Foto relevan Indonesia — konteks lokal, tools nyata, orang Indonesia
Hindari
✗
Multiple gradient competing dalam satu layout
✗
Emoji sebagai ikon — tidak profesional
✗
Terlalu banyak font weight — cukup 2-3 weight per layout
✗
Orange lebih dari sekali per visual — warna aksen kehilangan kekuatan
✗
Warna di luar approved palette — pink, hijau, kuning dominan dilarang

06 — Carousel Production

Mobile-First Carousel & 9:16 Adaptasi

Aturan produksi carousel — typography readability di feed HP, IG-master format, safe zones, slide indicator placement, closing slide convention, dan font fallback untuk special characters.

Format Master: IG 1:1

Carousel master adalah 1080×1080 (IG-native) sebagai source-of-truth. TikTok & IG Reels/Stories adalah derivative dari master IG via letterbox top + bottom (Deep Brown bg) ke 1080×1920. Master 1:1 di-place tepat di tengah kanvas 9:16 — letterbox otomatis berfungsi sebagai safe zone TikTok.

PlatformFormatCatatan
IG Feed Carousel1080×1080 (master)Source-of-truth — semua content didesain di sini. QC anchor di kanvas ini.
IG Reels / Stories1080×1920 (derived)Letterbox top 420px + bottom 420px (Deep Brown bg). Master 1:1 di tengah.
TikTok Slideshow1080×1920 (derived)Sama dengan IG Reels — content master di tengah, top/bottom letterbox = safe zone.
Naming: master gunakan slide-01.png … slide-NN.png (1080×1080). Variant 9:16 boleh ditambah suffix slide-NN-9x16.png bila diperlukan terpisah; default cukup master IG karena letterbox di-generate on-export.
Don't: Mendesain langsung di kanvas 9:16 lalu meng-crop ke IG 1:1 — content akan terpotong. Selalu mulai dari master IG, lalu letterbox keluar.

Mobile-Readable Typography Minimums

Sizing minimum agar konten kebaca pada feed HP. Render canvas 1080-pixel di-scale ~36-39% pada feed iPhone (lebar 390-420px) — pixel canvas dikalikan ~0.36 untuk dapat ukuran on-screen. Designer melihat 1080-pixel canvas, audience melihat 390-pixel feed.

Saat master IG 1:1 di-letterbox ke 1080×1920, top + bottom letterbox harus mengakomodasi TikTok native UI (status bar, follow button, caption, action stack).

Brand handle & CTA: Wajib diletakkan di atas bottom safe zone (y < 1440). Jangan andalkan posisi y > 1440 — akan tertutup TikTok caption.

Slide Indicator Placement

Slide indicator (mis. 4 / 7) adalah elemen dekoratif yang tidak boleh nabrak konten utama saat content stack lebih panjang.

Why 9:16 = top: dengan content vertically centered dalam safe area, indicator absolute di bottom akan tabrakan dengan footer-line ketika content tinggi. Top-right sudah berada di top safe zone, tidak konflik dengan content.

Closing Slide Convention

Setiap deck wajib punya closing slide dengan stack berikut, dari atas ke bawah:

  1. Eyebrow — context label (mis. "3 Pertanyaan Reflektif")
  2. Question stack / list konkret — pertanyaan refleksi atau action items, bukan abstraksi
  3. Footer italic — anchor pernyataan dalam Playfair italic
  4. CTA orange — momen spesifik kapan pakai (mis. "Simpan buat weekly meeting tim.")
  5. Sub-CTA — prompt refleksi singkat
  6. "Follow for more →" — Sora 800, Kerja Orange, di atas brand handle
  7. Brand handle — cukup @username (TikTok) atau RAHMAN RAMSI · @username (IG), tanpa tagline panjang
Don't: Tagline panjang setelah handle. Audience tidak baca tagline — handle saja sudah cukup branding.

Font Fallback untuk Special Characters

Sora variable font tidak punya glyph untuk semua Unicode characters (mis. → U+2192, ↗ U+2197). Saat headline pakai Sora 800, special chars tampil sebagai tofu (kotak kosong).

Don't: font-family: 'Sora', sans-serif untuk teks yang mengandung arrow / panah / simbol khusus.
Do: font-family: 'Sora', 'Plus Jakarta Sans', sans-serif — fallback per-character ke PJS yang punya glyph lengkap. Visual tetap dominant Sora untuk huruf, hanya char khusus yang fall back.

Terracotta & Gold sebagai Teks

Gold tidak memenuhi AA untuk teks apapun di background putih. Terracotta oke di ukuran besar. Gunakan:

  • Terracotta untuk teks besar (>18px bold) — OK
  • Gold untuk elemen dekoratif (border, badge, icon) — OK
  • Gold sebagai CTA dengan teks Deep Brown — OK
  • Gold untuk teks kecil (<18px) — Hindari, ganti Deep Brown atau Terracotta

Ukuran Minimum Interaktif

  • Touch target minimum: 44x44px (WCAG 2.5.5)
  • Ukuran font minimum body: 14px
  • Ukuran icon minimum: 20px (inline), 24px (standalone)
  • Line height body minimum: 1.5
  • Focus ring: 3px solid #B5452C, offset 2px

09 — Brand Compliance

Impeccable Self-Check

Setiap output visual WAJIB melewati checklist ini sebelum diserahkan ke QC. Tidak ada toleransi kelalaian.

Palette approved — hanya warna dari approved palette Direction B Warm Light (Warm Cream #FFF8F0, Deep Brown #1E1810, Body Brown #3D3025, Terracotta #B5452C, Gold #D4A017, Warm Stone #E8DDD3, Brown Muted #8B7355, Cream Dark #F5EDE3, White #FFFFFF)
Gold ≤ 1x per layout — Gold (#D4A017) maksimal satu elemen per layout. Elemen struktural (accent bar, nav dots) dikecualikan.
Font: Sora + Plus Jakarta Sans — heading Sora (700-800), body Plus Jakarta Sans (400-700). No other fonts.
≥ 2 visual language elements — dot grid, vertical accent bar, decorative number, step diagram, photo overlay. Minimal 2 per output.
Dimensi sesuai platform spec — IG 1080x1080, LinkedIn 1200x628, Twitter 1200x675, Reel 1080x1920
No emoji icons — SVG line icons only (stroke 1.5, 24x24 grid, Lucide-compatible)
Branding hadir — "Rahman Ramsi" visible di setiap output
Tone anti-hype — praktis, approachable, fokus pada hasil nyata. Hindari klaim bombastis dan estetika overpromising.
Body ≥ 32px (IG) atau ≥ 48px (9:16) — agar terbaca di feed HP setelah scaling ~36-39%
Eyebrow ≥ 24px (IG) / ≥ 32px (9:16) — UPPERCASE, letter-spacing 0.16em

9:16 safe zones clear — top 240px + bottom 480px tidak ada teks penting; konten vertically centered
