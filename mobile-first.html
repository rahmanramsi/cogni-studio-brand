Design System v3.1 · 2026-05-01

Mobile-First Carousel & Safe Zones

Update penting setelah produksi deck "OpenAI Workspace Agents" — typography di-bump untuk kebacaan di feed HP, TikTok safe zones formalized, dan format carousel disatukan jadi satu sumber konten untuk IG & TikTok.

01 · Konteks

Kenapa update ini ada?

Saat deck pertama (v3.0) di-render ke PNG dan di-view di feed HP (~390-420px lebar), body 18-22px hanya tampil ~6-8px on-screen — tidak terbaca. User feedback: "ukuran text terlalu kecil untuk ukuran HP."

Selain itu, pada TikTok native UI, heading di top canvas tertutup back-button + profile, dan caption di bottom menutup CTA. Konten harus dirancang dengan asumsi safe zone, bukan full canvas.

Prinsip: Designer melihat 1080-pixel canvas, audience melihat 390-pixel feed. Sizing harus dirancang untuk yang dilihat audience, bukan canvas absolute.
02 · Typography

Mobile-Readable Sizing Minimums

Sizing minimum agar konten kebaca pada feed HP. Render canvas 1080-pixel di-scale ~36-39% pada feed iPhone (lebar 390-420px), maka pixel canvas dikalikan ~0.36 untuk dapat ukuran on-screen.

Do: Trim copy lebih agresif jika perlu untuk muat dengan font size baru. Whitespace = design.

05 · IG-Master Format

IG 1:1 sebagai Master, 9:16 sebagai Adaptasi

Standar carousel adalah 1080×1080 (IG-native) mengikuti keputusan di AIC-51. Master IG menjadi source-of-truth — TikTok Slideshow & IG Reels/Stories adalah derivative dari master IG dengan letterbox top + bottom (Cogni Navy bg) ke 1080×1920.

PlatformFormatCatatan
IG Feed Carousel1080×1080 (master)Source-of-truth — semua content didesain di sini. QC anchor di kanvas ini.
IG Reels / Stories1080×1920 (derived)Letterbox top 420px + bottom 420px (Cogni Navy bg). Master 1:1 di-place tepat di tengah.
TikTok Slideshow1080×1920 (derived)Sama dengan IG Reels — content master di tengah, top/bottom letterbox berfungsi sebagai safe zone (lihat §03).
Benefit: Satu master IG 1:1 → multi-platform via letterbox script. QC anchor jelas di IG-native, TikTok adaptasi otomatis hadir di safe zone tengah.
Naming: master gunakan slide-01.png … slide-NN.png (1080×1080). Variant 9:16 boleh ditambah suffix slide-NN-9x16.png bila diperlukan terpisah; default cukup master IG karena letterbox di-generate on-export.
Don't: Mendesain langsung di kanvas 9:16 lalu meng-crop ke IG 1:1 — content akan terpotong. Selalu mulai dari master IG, lalu letterbox keluar.
06 · Closing Slide

Konvensi Slide Penutup (Slide N)

Setiap deck wajib punya closing slide dengan stack berikut, dari atas ke bawah:

  1. Eyebrow — context label (mis. "3 PERTANYAAN BUAT LO")
  2. Question stack / list konkret — pertanyaan refleksi atau action items, bukan abstraksi
  3. Footer italic — anchor pernyataan (mis. "Belum ada jawaban benar. Tapi lo harus mulai *ngelacak*.")
  4. CTA orange — momen spesifik kapan pakai (mis. "Simpan buat weekly meeting tim.")
  5. Sub-CTA — prompt refleksi singkat (mis. "Cek: kantor lo lagi pake AI yang mana?")
  6. "Follow for more →" — Sora 800, Kerja Orange, di atas brand handle
  7. Brand handle — cukup @username (TikTok) atau RAHMAN RAMSI · @username (IG)
Don't: Tagline panjang setelah handle ("@username — AI peta lokal"). Audience tidak baca tagline — handle saja sudah cukup branding.
Do: "Follow for more →" sebagai CTA eksplisit. TikTok & IG audience punya CTA muscle memory untuk ini.
07 · Font Fallback

Special Characters & Font Fallback

Sora variable font tidak punya glyph untuk semua Unicode characters (mis. → U+2192, ↗ U+2197). Saat headline pakai Sora 800, special chars tampil sebagai tofu (kotak kosong).

Don't: font-family: 'Sora', sans-serif untuk teks yang mengandung arrow / panah / simbol khusus.
Do: font-family: 'Sora', 'Plus Jakarta Sans', sans-serif — fallback per-character ke PJS yang punya glyph lengkap. Visual tetap dominant Sora untuk huruf, hanya char khusus yang fall back.
08 · QC Checklist

Self-Check Sebelum Submit (v3.1)

Tambahan dari brand compliance v3.0 — wajib divalidasi pada setiap output mobile-first.

  • Body ≥ 32px (IG) atau ≥ 48px (TikTok)
  • Eyebrow ≥ 24px (IG) atau ≥ 32px (TikTok), UPPERCASE, letter-spacing 0.16em
  • TikTok safe zones — top 240px + bottom 480px clear dari teks penting
  • Konten vertikal di-center dalam safe area (justify-content: center)
  • Slide indicator tidak nabrak konten — IG bottom-left, TikTok top-right
  • Brand handle di atas bottom safe zone, tanpa tagline panjang
  • "Follow for more →" hadir di slide penutup, font Sora + PJS fallback
  • Special chars punya font fallback (arrow, panah, dll)
  • Format IG-master — 1080×1080 master, naming slide-NN.png; 9:16 variant via letterbox (bila perlu)
