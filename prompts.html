Semua Platform
Base Style Prompt
Style: clean modern professional, deep warm brown background (#1E1810) or warm cream (#FFF8F0), terracotta accent highlights (#B5452C), minimal warm gold accent (#D4A017), geometric sans-serif typography, dot grid texture overlay, flat design with subtle depth, Indonesian professional aesthetic, approachable not corporate rigid Visual language: vertical 3px gold accent bar on left edge, subtle radial dot grid pattern (terracotta dots 8% opacity), strong typographic hierarchy, Lucide-style SVG line icons (stroke 1.5px) Quality: high resolution, print quality, sharp edges, no blur artifacts, professional layout Negative: no emoji, no gradient slop, no neon colors, no excessive decoration, no Comic Sans, no clip art, no watermark, no border frame unless specified, no blue/navy/cool tones, no orange #F77F2A

Untuk Midjourney: tambahkan setelah prompt dengan --no [negative terms]. Untuk DALL-E/Firefly: gunakan kolom "Things to avoid". Untuk SD/ComfyUI: masukkan ke negative prompt box.

Tool Parameter Penting Catatan Brand

Canva AI Magic Media → pilih ratio. Gunakan brand kit untuk lock warna. Setup Brand Kit di Canva dengan warna & font Rahman Ramsi sebelum generate. Style consistency lebih mudah dikontrol.

Tips Konsistensi Visual
Cara memastikan output AI tetap on-brand di semua konten
Workflow yang Direkomendasikan:
1. Generate dengan prompt lengkap → 2. Validasi dengan Brand Compliance Checklist → 3. Jika warna off, edit di Canva/Photoshop dengan Color Balance/Hue-Saturation → 4. Export resolusi penuh → 5. Submit ke Brand Visuals agent untuk QC final.
