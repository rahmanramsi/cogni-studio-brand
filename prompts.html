Negative Prompt
AVOID / NEGATIVE PROMPT: emoji as icons, neon colors, purple gradients, pink tones, Comic Sans, Arial, Times New Roman, generic stock photo background, excessive decoration, watermark, copyright mark, blurry text, small illegible text, cluttered layout, rainbow colors, yellow dominant, red dominant, green dominant, clip art style, cartoon illustration, hand-drawn style, childish aesthetic, corporate clipart, excessive drop shadow, bevel emboss, beveled 3D buttons, glowing neon outlines, tech startup cliché (circuit board pattern, binary code rain), excessive bokeh, lens flare overuse, generic gradient mesh background, confetti, balloons, stars scattered, hearts, motivational quotes font (Impact/Broadway), ALL CAPS everywhere, too many fonts mixed
Untuk Midjourney: tambahkan setelah prompt dengan --no [negative terms]. Untuk DALL-E/Firefly: gunakan kolom "Things to avoid". Untuk SD/ComfyUI: masukkan ke negative prompt box.

Catatan Per AI Tool
Penyesuaian prompt untuk setiap platform AI image generation

Tool-Specific Parameters

Reference
Tool Parameter Penting Catatan Brand
Midjourney --ar 1:1 (IG) / --ar 16:9 (LI/TW) / --ar 9:16 (Reel)
--style raw untuk lebih literal
--no [terms] untuk negative		 Tambahkan --style raw --v 6.1 untuk kontrol lebih. Hex warna kadang tidak presisi — verify setelah generate.
DALL-E 3 Pilih ukuran: 1024×1024 (IG), 1792×1024 (LI/TW), 1024×1792 (Reel) Sangat baik mengikuti instruksi tipografi. Sebut font name secara eksplisit.

Stable Diffusion Model: SDXL atau Flux. Gunakan negative prompt box terpisah. Steps: 30+. Untuk konsistensi tinggi, gunakan LoRA brand style atau IP-Adapter dengan reference image dari design system.
Canva AI Magic Media → pilih ratio. Gunakan brand kit untuk lock warna. Setup Brand Kit di Canva dengan warna & font Cogni Studio sebelum generate. Style consistency lebih mudah dikontrol.

Tips Konsistensi Visual
Cara memastikan output AI tetap on-brand di semua konten
Workflow yang Direkomendasikan:
1. Generate dengan prompt lengkap → 2. Validasi dengan Brand Compliance Checklist → 3. Jika warna off, edit di Canva/Photoshop dengan Color Balance/Hue-Saturation → 4. Export resolusi penuh → 5. Submit ke Brand Visuals agent untuk QC final.
