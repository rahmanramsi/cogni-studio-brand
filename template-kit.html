Brand Compliance Checklist

Validasi setiap output visual sebelum publish. Centang semua item sebelum diserahkan.

Warna

Primary: Cogni Navy #0F2A4A digunakan untuk headline
Secondary: Studio Teal #0D9BAE digunakan untuk aksen & link
Kerja Orange #F77F2A maksimal 1× per layout (CTA saja)
Tidak ada warna di luar palette brand yang disetujui

Tipografi

Heading menggunakan Sora (atau system fallback)
Body menggunakan Plus Jakarta Sans (atau system fallback)
Tidak ada font di luar spec yang ditambahkan
Line height heading: 1.0–1.15 · body: 1.5–1.7

Visual Language

Minimal 1 elemen visual language hadir (dot grid / accent bar / step diagram / large number)
Tidak menggunakan emoji sebagai ikon — hanya SVG line
Icon stroke: 1.5px, Lucide-style, 24px grid
Tone: clean, modern, approachable — bukan corporate kaku

Platform Specs

IG Carousel: 1080×1080px per slide
LinkedIn Post: 1200×627px
Twitter/X: 1200×675px
Reel Thumbnail: 1080×1920px

Konten & Brand Voice

Pesan utama: praktis & approachable
Tone bahasa: praktis, approachable, tidak berlebihan
Branding "Rahman Ramsi" hadir di setiap visual
Target audience: kamu & UMKM Indonesia

Final QC sebelum Publish

Export resolusi penuh (bukan screenshot kecil)
Teks tidak terpotong di semua ukuran
Safe zone: elemen penting tidak di 5% tepi canvas
Review visual oleh Brand Visuals agent / Argus sebelum publish
